## ✨ Sobre este repositório

Este repositório reúne atividades e exercícios desenvolvidos durante a disciplina de **Algoritmos**, no primeiro ano do meu Curso Técnico em Informática.

Foi meu primeiro contato com a programação: desde aprender a abrir e utilizar o **Visual Studio Code (VS Code)** até compreender como construir algoritmos, resolver problemas e organizar dados.

Os códigos são introdutórios e representam uma etapa importante da minha aprendizagem. Mantive este repositório como registro da minha evolução ao longo do curso. 💛

## 🗂️ O que significa CRUD?

**CRUD** é uma sigla em inglês para quatro operações muito comuns em sistemas:

| Sigla | Inglês | Significado |
|:--:|:--|:--|
| **C** | Create | Criar ou cadastrar um registro. |
| **R** | Read | Ler, consultar ou listar registros. |
| **U** | Update | Atualizar informações existentes. |
| **D** | Delete | Excluir um registro. |

Por exemplo, em um programa de cadastro de alunos, essas operações permitem **cadastrar um aluno, consultar seus dados, alterar informações e excluir um cadastro**.
